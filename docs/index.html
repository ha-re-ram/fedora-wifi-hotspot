Fedora Wi-Fi Hotspot

Turn your Fedora Linux machine into a powerful, secure Wi-Fi access point with a single click. Say goodbye to terminal configurations.

Download .tar.gz View on GitHub
✨

Native GNOME GUI

A beautifully integrated, responsive desktop application built specifically for the modern Fedora desktop experience.

🚀

Concurrent AP

Share your existing Wi-Fi connection through the exact same adapter without dropping your internet connection.

🔒

Passwordless Access

Once installed, secure sudoers integration means you never have to type your root password to start or stop the hotspot.
